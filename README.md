# vanshu.eth — Portfolio

Personal portfolio of Vanshika ([@vanshuETH](https://x.com/vanshuETH)) — crypto content creator: video content, growth, marketing & social media.

Built with **React + TypeScript + Vite + Tailwind CSS + shadcn/ui** + framer-motion.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `dist/`.
